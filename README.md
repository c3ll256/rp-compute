# Makit Compute

## What it is

Makit Compute turns a Raspberry Pi 4B into a compact Linux terminal. An orange bezel frames a tilted, 400 × 240 monochrome display in a warm-white 3D-printed case. On screen, a little pixel character sits at a desk and acts out what Codex is doing on the Pi.

## Why it is worth making

You can leave Codex working on a long task and get on with something else. A glance at the character tells you whether to let it work or step in and answer a question. If you like building hardware, an 8-pin connector under the front cover gives you a place to plug in a sensor or button module of your own design.

## What it is like to use

Plug in USB-C power and the character settles in at its desk. It types while Codex works, shows a question mark when Codex needs your input, and gives a little hop when the task is done. Connect a keyboard and press `Ctrl+Alt+T` to use the screen as a Linux terminal. Press it again to return to the pixel room while your command keeps running. For longer sessions, you can use the web terminal from a browser on the same network.
