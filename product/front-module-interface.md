# 可拆前平台盖板与用户拓展件安装接口

前平台盖板为独立可拆换零件；CAD零件名为front_module_cover，可单独选中、隐藏和移动。卸下四角螺丝后沿 +Z 提起盖板，露出壳体安装窗口和内部扩展母座；用户设计的拓展件替换整块盖板，沿用定位座、定位舌及四角固定点。默认盖板仅有四个沉头固定孔，没有中央电气接口通孔或 PCB 螺丝避让通孔。PCB 由上壳独立支撑，拆盖板不会释放 PCB。

坐标使用外壳 CAD 世界系，X 向右、Y 向后、Z 向上，单位 mm。固定上壳平台顶面 Z=27；屏舱前沿名义高出固定平台 1 mm。

| 共用机械接口 | 默认尺寸 |
| --- | --- |
| 盖板中心 | X=0，Y=-34 |
| 外形及角半径 | 70×37，R1.8 |
| 基础板厚 | 1.4 |
| 壳体定位座 | 70.3×37.3，R2.0，深1.4 |
| 壳体贯通窗口 | 54×26，R1.5 |
| 盖板背面定位舌 | 53.4×25.4，R1.2，深0.6 |
| 四角固定点 | X=±31，Y=-49/-19 |
| 固定螺丝 | 四枚 ISO7046 M2×4 沉头螺丝 |
| 盖板平面顶面 | Z=27 |
| 母座背面盲凹腔 | 中心(0,-34)，10.35×5.28，凹腔顶Z26.354999 |

盖板外表面全平，顶面Z27，没有中央凸起或贯通孔。母座模型顶面Z26.254999，背面凹腔留0.1mm名义空气间隙，中央顶壁0.645001mm、样机默认下限0.6mm；其余主板厚1.4mm。凹腔形状取自现有发布母座包络，属于非承力薄顶。薄顶打印、收缩和母座实际高度须实物确认；不能假定0.1mm名义间隙能覆盖制造误差。盖板为单个实体，四角螺丝拆下后整块提起，定位接口不变。

两处 PCB 固定螺丝仍为 ISO4762 M2×4，在螺丝头与板背面之间各加一个直径4.8、厚1.2的独立 PLA 样机垫片。垫片孔和打印接收孔由 printed-screw-joint-v1 生成。板底 Z21.8 和板上安装梁保持；螺丝入口降至 Z20.6，螺丝尖端名义 Z24.6，盖板下侧让空到 Z25.1。无需在盖板上开螺丝避让通孔。

拓展件独立承载其器件，不能让 GPIO 母座承受安装载荷。避开板上元件、安装梁、固定螺丝、线束和屏舱。54×26 是壳体窗口尺寸，不代表整块窗口下方均为空闲器件空间；以当前装配模型为准。上述尺寸是样机接口默认，打印收缩、螺孔寿命和承载尚未实测。

## 内部八针接口

当前精简基板使用 Samtec HLE-104-02-G-DV，2×4、2.54间距、正面直立母座，名义壳高3.66。连接器世界中心(0,-34)。针号来自已有基板源及制造发布，使用自定义分配，不等同于 Pi 排针1–8。

| 模块针位 | 网络 | Pi物理针位 |
| --- | --- | --- |
| 1 | AUX_3V3 | 独立辅助3.3V电源 |
| 2 | GND | 共同参考地 |
| 3 | GPIO2 / SDA | 3 |
| 4 | GPIO3 / SCL | 5 |
| 5 | GPIO10 / MOSI | 19 |
| 6 | GPIO9 / MISO | 21 |
| 7 | GPIO11 / SCLK | 23 |
| 8 | GPIO7 / CE1 | 26 |

Pi针位证据为[Raspberry Pi官方GPIO图](https://raw.githubusercontent.com/raspberrypi/documentation/master/documentation/asciidoc/computers/raspberry-pi/images/GPIO-Pinout-Diagram-2.png)，母座尺寸见[Samtec HLE产品资料](https://www.samtec.com/products/hle)。扩展接口正常模块预算100mA，只接受本板 AUX_3V3 供电的3.3V逻辑模块；不引出5V，禁止外部电源反灌。MOSI/SCLK与显示共享，模块使用CE1并协调软件与启动状态。此机械修改未改变电路或针位分配，配套公排针、插入深度、子板高度和电气功能由具体模块验证。

更换前先正常关机并拔掉 Pi USB-C 电源；有其他电源时一并隔离。断电后卸下盖板并接插模块，完成固定后再通电；不支持热插拔。可使用拆下的盖板作为外形及安装孔模板。未进行实际打印、插接、扭矩或模块功能测试。
