# 可拆前平台盖板与用户拓展件安装接口

前平台盖板为独立可拆换零件。卸下四角螺丝后沿+Z提起盖板，露出上壳窗口和内部扩展母座；拓展件沿用平面承托和四角固定点。盖板底面取消定位舌及凸台，四角沉头孔为唯一贯通孔。PCB由上壳独立支撑，拆盖板不会释放PCB。

坐标使用外壳CAD世界系，X向右、Y向后、Z向上，单位mm。

| 共用机械接口 | 默认尺寸 |
| --- | --- |
| 盖板中心 | X=0，Y=-34 |
| 外形及角半径 | 70×37，R4（圆角增大请求的默认值） |
| 平板厚度 | 2.4 |
| 上表面边缘倒角 | 0.4 |
| 承托方式 | 平底直接贴合上壳平台，无定位舌、无下沉定位座 |
| 上壳贯通窗口 | 54×26，R1.5；局部保留PCB安装横梁 |
| 四角固定点 | X=±29.5，Y=-45/-23，孔距59×22 |
| 固定螺丝 | 四枚M3×6、90°沉头螺丝（默认ISO10642头型，头径6mm） |
| 盖板底面/上壳平台 | Z=27 |
| 盖板顶面 | Z=29.4 |
| 母座名义包络顶面 | Z=26.254999 |
| 盖板对母座名义空气间隙 | 0.745001 |

盖板为单个平板实体，无底部凸起或局部母座凹腔；底面朝下、沉头孔朝上打印。默认PLA；沉头孔口径额外增加0.4mm、深度增加0.2mm，头部名义沉入0.2mm；接收孔补偿由套件保持，打印翘曲、孔位与实际落座仍需试装。不得靠拧紧螺丝拉平翘曲盖板或向母座施压。

PCB采用两枚ISO4762 M2×3圆柱头内六角螺丝，从板底直接固定到上壳安装梁；取消两枚独立打印垫片。板底仍为Z21.8，原2.2mm板孔和安装梁保留，螺丝尖端名义Z24.8，距盖板底面2.2mm；盖板无需螺丝尖让位孔。

拓展件独立承载器件，不能让GPIO母座承受安装载荷。避开板上元件、安装梁、固定螺丝、线束和屏舱。54×26只是上壳窗口尺寸，不代表整块窗口下方均为空闲器件空间；以装配模型为准。

## 内部八针接口

当前精简基板使用 Samtec HLE-104-02-G-DV，2×4、2.54间距、正面直立母座，名义壳高3.66。连接器世界中心(0,-34)。针号来自已有基板源及制造发布，使用自定义分配，不等同于 Pi 排针1–8。

| 模块针位 | 网络 | Pi物理针位 |
| --- | --- | --- |
| 1 | AUX_3V3 | 独立辅助3.3V电源 |
| 2 | GND | 共同参考地 |
| 3 | GPIO2 / SDA | 3 |
| 4 | GPIO3 / SCL | 5 |
| 5 | GPIO10 / MOSI | 19 |
| 6 | GPIO9 / MISO | 21 |
| 7 | GPIO11 / SCLK | 23 |
| 8 | GPIO7 / CE1 | 26 |

Pi针位证据为[Raspberry Pi官方GPIO图](https://raw.githubusercontent.com/raspberrypi/documentation/master/documentation/asciidoc/computers/raspberry-pi/images/GPIO-Pinout-Diagram-2.png)，母座尺寸见[Samtec HLE产品资料](https://www.samtec.com/products/hle)。扩展接口正常模块预算100mA，只接受本板 AUX_3V3 供电的3.3V逻辑模块；不引出5V，禁止外部电源反灌。MOSI/SCLK与显示共享，模块使用CE1并协调软件与启动状态。此机械修改未改变电路或针位分配，配套公排针、插入深度、子板高度和电气功能由具体模块验证。

更换前先正常关机并拔掉 Pi USB-C 电源；有其他电源时一并隔离。断电后卸下盖板并接插模块，完成固定后再通电；不支持热插拔。可使用拆下的盖板作为外形及安装孔模板。未进行实际打印、插接、扭矩或模块功能测试。
