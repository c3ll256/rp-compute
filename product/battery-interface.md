# 用户自备电池：基板接口规范

状态：接口设计输入；不是某个电池的测试证书。用户已决定自己采购兼容电池，基板开发不再等待助手锁定电池品牌/型号。保留既定3.7V、3300mAh、Li-ion要求；不增加续航时长保证。

## 购买时匹配的条件

| 项目 | 基板兼容目标 | 来源/限制 |
|---|---|---|
| 类型 | 1S、标称3.7V、3300mAh、4.2V充电体系 | 电压/容量/化学体系为用户要求；1S与4.2V为设计默认，不兼容2S、LiFePO4或需要不同充电制度的包 |
| 保护 | 厂家完成保护板、绝缘与线束的成品包 | 不使用裸电芯，不要求用户焊电芯或旁路保护 |
| 持续放电 | 整包至少8A的设计选型目标 | 必须包括PCM、引线、接头；容量、裸电芯倍率或瞬时峰值不能替代整包持续额定 |
| 连接器 | 电池端AMASS XT30U-F；基板端XT30U-M成品引线 | 本项目默认。按壳体+/−及实测极性核对；不是JST-PH，也不是直接焊在PCB上的插座 |
| 线束 | 默认18AWG柔性铜线、约100mm；厂家端接并绝缘 | 长度可随实际装配调整，不能影响整包电流与应力释放；不让用户改造带电包 |
| 充电 | 基板初始设定目标4.2V、480mA | 不是任意包可充的保证；整包允许范围须覆盖充电器电压/电流全容差。禁止直接沿用上电1040mA默认值 |
| 测温 | 两只项目103AT-2温度探头贴合电池绝缘外表面 | 充电器和监督器分别监测；固定/绝缘不能刺穿或挤压电池。默认只在5–40°C充电，且不超出厂家允许范围 |
| 尺寸 | 当前未冻结 | 记录包括PCM、绝缘、接头、出线弯曲和公差的整包尺寸；买到后再冻结电池仓，85×115×40mm仍非适配承诺 |

≥8A是给电池采购留余量的要求，不提高BQ25622电池通路6A的限制。基板必须在设计和原型验证中遵守这个更低的系统限制。

## 首次连接与启用

1. 保持外部电源断开，核对电池类型、标签/资料、连接器和极性；不要只看颜色或“插得上”。
2. 将厂家允许充电参数写入配置并核对；资料不明时，充电器CE保持禁充。量产固件/硬件尚未实现这种控制，不能把本文当成已有功能。
3. 使用受控实验电源完成板级调试，再由工程人员验证实际电池的启动压降、温升、保护恢复与低电压关机余量。保护板硬切不能替代Linux正常关机。
4. 完整电池包不合适时更换兼容成品包，不拆保护板、不现场焊改电芯。

用户现在无需提交型号才能继续基板设计。之后给出商品资料或实物尺寸即可核对；电池仓最终适配及带电测试不能省略这一核对。
