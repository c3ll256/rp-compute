# Pi Zero 掌上 / 桌面小电脑

## 当前状态
需求草案，等待五项具体产品选择；不是已验证的硬件方案。本轮交付需求、研究记录和后续交付约定，不生成 PCB 或外壳模型。

## 已明确的需求
- Raspberry Pi Zero 系列驱动；原版 Zero、Zero W 或 Zero 2 W 的具体版本尚未指定。
- 显示器固定为 Sharp LS027B7DH01，不擅自替换为其他后缀或相近型号。
- 机身带 USB-A 和 USB-C 接口。
- 内置可充电电池，可以拔掉外部电源独立工作。
- 外观参考用户的两张图片，兼顾掌上拿持和桌面放置。

## 外观解读与公开默认值
图片可见橙色屏幕外框、黑色内边框、浅色圆角机身、上部横向屏幕和下部大面积操作区；第二张图右下有圆形控制件。图片不能证明触控、铰链、灯条、麦克风、扬声器或原产品内部结构。

以下均为可修改的设计默认值，不是用户已确认条件：
- 第一版采用固定倾角的一体式机身，不默认增加翻盖铰链。
- 橙色屏框、深色内框、浅色底座；底面防滑，可放桌面操作。
- 初始布局目标约宽 85 × 深 115 × 最大高 40 mm，仅作为排布起点，不能当作已验证装配尺寸。实际尺寸在硬件包完成后按真实器件确定。
- 外壳优先考虑 FDM 原型；后续 CAD 交付 STEP，打印排版与 3MF 为另行请求的阶段。
- USB-A 暂定 1 个 USB 2.0 主机接口，服务键盘、鼠标或 U 盘；不默认承担手机快充。外设供电预算由硬件阶段确定并公开。
- USB-C 暂定 1 个，仅用于 5 V 输入、充电及运行供电；其数据功能是待确认选项。
- 候选主板优先考虑 Pi Zero 2 W，但未替用户确认具体主板，也未确认其本轮机械接口。
- 电池初步方向为受保护的单节可充电锂电池方案，具体电芯、容量、充电电流、保护和温度监测由硬件阶段选定。
- 目标支持边充边用、接入/拔出合格外部电源不重启；需要带电源路径管理的设计，不能仅把充电板与升压板简单拼接后宣称实现。
- 提供电量/低电量提示、正常关机及低电量受控关机；避免把日常关机设计为直接切断 Linux 电源。
- 第一版默认环境光下使用，不包含附加屏幕照明、触摸覆盖层、麦克风、扬声器和装饰灯；如需要应作为明确功能加入。
- 候选 UI 是适配 400×240 黑白显示的简洁菜单、文字与像素图标；不默认等同于适合完整桌面浏览器或视频的小型笔记本。
- 初步续航目标 4 小时，尚待用户选择；不能据此先行承诺电池容量或实测续航。

## 已核实的屏幕事实
来源：Sharp 原厂规格书 LCY-1210401A，由 DigiKey 托管，已保存为 `product/references/LS027B7DH01-sharp-2010.pdf`。文件属于较早期规格资料，硬件选型时仍须核对实际供货版本。

- PDF 第 10 页（印刷第 7 页）：2.7 英寸、400×240、单色 Memory LCD；面板每像素 1 bit，支持串行数据及逐行更新。
- 同页：显示区 58.8×35.28 mm；模块本体 62.8×42.82×1.64 mm，尺寸明确不包括突出部分；FPC、弯折和完整外形应在硬件阶段按尺寸图复核，不能只用这个长方体做外壳。
- 同页：资料描述反射/透反射显示，可借助额外背光做透射模式，但透过率约 0.35%；本项目不默认有照明或暗处可读。
- PDF 第 11 页（印刷第 8 页）：10 个接口端子，包含 SCLK、SI、SCS、EXTCOMIN、DISP、VDDA、VDD、EXTMODE、VSS、VSSA；需要管理 COM 极性反转，不是接 HDMI 即可使用的显示器。
- PDF 第 13 页（印刷第 10 页）：VDD/VDDA 推荐 4.8–5.5 V，典型 5 V。SCLK/SI/SCS/DISP/EXTCOMIN 的 VIH 最小 2.70 V，低电平上限 VSS+0.15 V。因此不能从“5 V 电源”推出“必须用 5 V GPIO”，也不能在未检查输出低电平、时序和掉电反灌前宣称 Pi GPIO 直连已经验证。
- PDF 第 7 页（印刷第 4 页）：长时间静态图像需要刷新以减少残影风险；具体刷新和 COM 时序在驱动设计中落实。

## 待确认的五项产品选择
1. `compute_variant`：使用哪一版 Pi Zero；若已持有主板，提供型号或照片。
2. `primary_use`：主要是桌面信息/像素宠物、终端工具、便携文字阅读/记录，还是其他用途。
3. `local_input`：下半区采用按压旋钮与按钮、触摸板与按钮、内置小键盘，还是主要依赖外接键盘。不能从图片臆测触摸功能。
4. `usb_c_role`：USB-C 只充电供电，还是也要接外设或连接另一台电脑传数据；USB-A 是否须同时工作随该选项明确定义。
5. `battery_runtime_hours`：轻度使用的目标续航选择 2、4 或 8 小时，或填写其他目标。

## 验收计划（目标，不代表已完成测试）
- 指定 Pi Zero 启动后，内置 LS027B7DH01 显示可操作的本地界面；测试全部显示行、黑白画面、文字可读性及 COM 反转。
- 选定机身控制方式可完成进入菜单、移动、确认和返回，核心用途无需临时调试线。
- 电池供电模式可启动和运行；USB-C 接入与拔出期间不得重启或损坏存储；低电量受控关机后再切断主电源。
- 续航按室温 20–25 °C、无附加照明、无 USB 总线供电外设、代表性轻负载记录测试；支持联网的选定主板以 Wi-Fi 连接空闲为基线。用户用途确定后细化工作负载。外设供电或高负载另测，不与基线混淆。
- USB-A 识别键盘与 U 盘，验证声明的外设负载预算；若增加 USB-C 数据，按最终约定测试单独和同时使用的角色。
- 屏幕无夹持应力，FPC 弯折与电池留量合理，充电与运行温升、电池保护、端口插拔和桌面稳定性均须原型实测。

## 后续硬件阶段负责的工作
由设计助手负责闭环，不属于要用户批准的整份方案：
- 按用户选定主板取得原厂规格、真实尺寸和可追溯模型；本轮内置 STEP 检索只返回 Pico 与 Pi 4，均不匹配，不予采用。
- 主板官网页面本轮被 403 拒绝，尝试的产品简介 PDF 地址返回 404；没有据此推断停产或不可购买，也没有假定端口坐标。原生网络检索本轮未返回可用条目。
- 复核 Zero 的 USB 主机/设备角色资源；若 C 口有数据功能，给出明确切换或扩展方案，不把同一对 D+/D− 并联到两个外部端口。
- 解析屏幕原厂完整外形图、FPC 节距/触点方向/弯折区域，选定连接器和显示驱动策略。
- 建立 Pi、屏幕、USB 外设及电源转换损耗的功耗预算，依据目标续航选电芯，并确定电源路径、升压、限流、保护与关机控制。
- 选择真实操作器件，固定器件位置、行程、安装尺寸和线缆空间；生成 BOM 与硬件约束后才进行 PCB 和配套外壳设计。
- 需求阶段不声明器件现货、价格、PCB 已布线、软件已实现或原型已通过测试。
