# 当前散热与固定方案

保留 Pi4B、85×115mm主体和21.8mm紧凑HAT高度。用户最新选择65×55×11mm的Pi4被动散热器；按厂家尺寸与照片，采用Geekworm P165-B单独散热器SKU100237。此前Pi5一体散热器建议已被这次选择取代。

主板四角仍固定到上壳。四个小托耳位于PCB下面，四颗ISO7046M2.5x6沉头螺丝穿过托耳与主板原孔，旋入散热器四角金属M2.5内螺纹；散热器和主板共用固定，无独立散热器上壳支架。主板原孔不加工沉头，外露模块盖及LCD压框螺丝采用ISO7046M2沉头。

独立NidecF16FB-05LLC鼓风扇保留16×16×4.5mm规格，靠近左侧壁，由简单托架和压框固定。热风不能朝前吹。屏舱下方左后侧四条进气槽按用户要求取消，恢复连续侧壁；左前侧风扇排气槽保留，前端不排热风。风扇仍向上吸气、向左排出，封闭进气槽后的整机进气路径和温升须实测。保持风扇最大厚度之上直径12mm、高3mm的吸气净空；无需跨过主板的高风罩。

HAT新增J_FAN两针JSTSH侧插接口，在板正面向前开口。PiGPIO物理2/4的5V经过HAT铜箔供给J_FAN1脚，GND接2脚，再接工厂预制插头线束；不占用逻辑GPIO，GPIO12继续用于LCDCOM。5V常转、额定40mA/0.2W，默认预留100mA/0.5W。细风扇线由工厂接到合格32AWG压接线，用户安装只插接，无焊接。

P165-B仅有厂家外形尺寸和照片，未获得原厂STEP；CAD鳍片、底部台阶、接口避让及0.25mm导热贴片均明确为参考，不据此保证实物导热接触。实物需检查底部接触高度、贴片压缩、四角螺纹深度与GPIO母座避让，再测试启动、电压、噪声和CPU/RAM持续负载温升。风扇静压仅5.5Pa，最终流量和散热性能尚未测量。

# BYOP Pi 4B GPIO基板终端套件


## 当前优先版本：屏幕与 8 针 GPIO 精简基板

用户确认取消当前精简版侧面电源按钮及按钮帽，对应开孔恢复连续侧壁；关机通过系统软件完成，不新增GPIO按钮电路。

用户确认使用 2.54 mm、2×4 双排直立母座；Pi 自身 USB-C 为精简版唯一供电入口；外壳开放该口，取消左侧多余的基板充电开口，使风扇支撑处保持连续侧壁。精简版由 Pi 40 针 GPIO 的 5 V 触点取电，只有显示和模块支路，不向 Pi 反向供电。不含电池、充电、升压、监督 MCU 或音频。Pi 平台为 raspberrypi/raspberry-pi-4-model-b。定制 PCB 是用户明确要求的屏幕与可换模块接口基板。

8 个触点的默认分配为：1=3.3V、2=GND、3=SDA(GPIO2)、4=SCL(GPIO3)、5=MOSI(GPIO10)、6=MISO(GPIO9)、7=SCLK(GPIO11)、8=CE1(GPIO7)。屏幕占用独立 CE0；COM 改由 GPIO12、DISP 由 GPIO25、屏幕电源使能由 GPIO24 控制。SPI共享总线须由驱动协调。针距相同不代表与Pi前8针兼容。

FPC按用户最新要求采用正面水平侧插首韩0.5-10P CTSJ-H2.0 119（C5373447），扩展口采用HLE-104-02-G-DV（3.66mm）低矮母座，移至前舱开孔中央，按数字针号保留接口功能。板外包络默认保留40×83.5mm、0.8mm厚，但扩宽中央及显示电子区以增加面积；所有实装元件在正面，背面仅Pi母座。两颗TSSOP14拉开，去耦仍靠近各自供电脚。FPC采用带详细库STEP的抽屉式上接触座；为解决窄条走线和接地回路拥堵，四层、内外1oz为本轮默认实现。布线、接地连通性和制造检查已通过，屏幕原生排线轻弯接入仍需机械核对。

扩展模块默认100mA预算，独立限流及3.3V稳压；仅断电更换，只接受本板供电的3.3V模块。显示保留必要的缓冲、去耦与受控电源。Sharp原厂规格书第11/13/14页已核对端子、逻辑电压和上下电时序；软件必须提供COM反转与关机清屏。当前紧凑板采用四层1oz、0.8mm板厚、40×83.5mm外包络；历史70×104mm两层样机板框已被取代。原生短排线仍需样板接插验证。

正面单面贴片布局的布线、制造和整机空间结果由设计发布记录报告；PCB检查不能替代实物接插、驱动和温升测试。

原 pi_baseboard 的电源完整版源文件及物料参考保留。下文电池、充电、Pi供电和联锁内容仅适用于完整版，不是当前精简版需求或采购清单；当前活动BOM只列精简版。

屏幕原生排线暂按13.7mm总长、±0.5mm估算误差继续设计，检查13.2–14.2mm两端情况；这是用户授权的默认估计，不是实测或厂商公差。总长沿排线从玻璃出线边缘量至端头，包含补强端和插入连接器的部分。排线周围按每侧0.5mm非接触间隙预留，不增加假想线长，不放宽0.45mm最小内弯半径及距玻璃0.8–6.0mm允许折弯区。无需再等待实测长度才能继续暂定布局，但最终适配仍未验证。

上外壳固定更新：用户要求紧凑板继续抬高，并固定在上外壳。当前 CAD 评估默认上抬4.3mm，板底Z21.8mm；由上外壳两处内侧横梁螺钉和后端限位承担固定，底盖及可拆模块盖不承受PCB固定载荷。用户已选择较高GPIO母座；本轮按Samtec ESQ-120-12-G-D厂家尺寸核对堆叠，实物插接和温升尚未测试。

### 当前紧凑板接口和散热调整

用户指定换高GPIO母座、降低8pin接口、FPC入口朝下。选ESQ-120-12-G-D（11.05mm）和HLE-104-02-G-DV（3.66mm），保持2.54mm配合间距。水平FPC入口按平面图下侧/前端-Y布局。主板底面默认Z21.8mm，比Z22.5试排下降0.7mm，仍由上壳固定。普通器件上方目标空气间隙≥1.5mm；温升、风流和屏幕原排线完整插装尚需验证。

当前FPC修订：用户确认原排线折回后露铜面朝上，授权改用水平上接触首韩0.5-10P CTSJ-H2.0 119（C5373447），保留向下/前方入口、紧凑板和上壳固定。原底接触要求由本次用户选择取代。排线总长仍按13.7±0.5mm暂估，安装尺寸须以新座的实际入口、止挡和锁扣空间复核。

FPC为代理按用户授权选择的首韩C5373447。推荐露铜≥3mm、补强≥4mm，最接近屏幕3.5/4mm端部。详细STEP来自嘉立创EDA/EasyEDA官方库（https://lceda.cn/，https://easyeda.com/）；有插槽和锁扣，但不证明实物插接公差。焊盘与原接口不同，须重新布线并核对针序及滑盖空间。
