# Pi4B基板：电源/联锁/插接的电气设计交接

状态：USB-C、充电路径、升压、Pi/LCD 分路、屏幕逻辑、ATtiny1616 监督器、盖联锁、充电 CE 许可和 GPIO 独立辅助供电均已写入单基板电路源。新增电路已通过编译及布局预览，整板布线和 DRC 仍待通过；尚不可制造或通电。BOM ready 只表示主要器件可支持电路设计，不是生产采购批准。电池由用户采购，接口见 battery-interface.md。监督器引脚、复位状态和充电条件见 design/pi_baseboard/controller-contract.md。

## 选定架构

```text
外部USB-C输入 -> TUSB320LAI 3A广告识别/硬件门控 -> TPS259531 -> BQ25622 VBUS
用户保护1S电池 -------------> BQ25622 BAT
BQ25622 SYS -> TPS61088 5.1V -> TPS22990主断开
                                  |-> TPS259470L -> Pi GPIO 5V/风扇
                                  |-> TPS259470L -> LCD 5V/显示逻辑LDO
                                  |-> TPS2553 -> TLV75533 -> GPIO AUX_3V3
SYS -> TLV75533 3V3_AON -> ATtiny1616 + 复位/锁存/整形
```

第二颗TPS259470LRPWR专供LCD，不把LCD接到可能从Pi反向供电的GPIO5V节点。TPS22990保留，VBIAS接未开关升压输出，热焊盘为VIN，不是GND。TPS61088关闭使能不等于输出电源隔离。

当前输入门控仅接受 USB-C 源的 3 A 电流广告；普通及 1.5 A 广告不启动。TUSB320LAI 的 OUT1/OUT2 经 SN74AHC1G32 控制 TPS259531 的低有效使能，47 kΩ 上拉保持启动默认关闭。这是未经过插拔、掉电和异常 CC 状态试验的设计默认，不能声称支持低电流源降档。BQ25622 的 CE 默认保持禁止充电；升压和主开关使能也默认下拉关闭。MCU 和硬件联锁连接已写入，编译已通过，布线、固件和启动状态验证仍未完成。

## 硬件联锁器件及连接意图

- D2F-01L：盖压到位时闭合COM—NO；COM接3V3_AON，NO接TPS3808的MR。MR用1kΩ固定下拉，正常闭合约3.3mA接点电流，断线/开盖保持低电平。这个电流是设计默认，接点寿命/低负载可靠性仍须按实际环境核实，非安全认证。NC不接，不改成开盖才靠接点导通拉低的失效方式。
- TPS3808G33DBVR：SOT-23-6，1=/RESET、2=GND、3=/MR、4=CT、5=SENSE、6=VDD。VDD和SENSE接3V3_AON，CT开路（12–28ms释放延迟，典型20ms）；/RESET用10kΩ上拉到AON。每颗逻辑器件近端100nF。MR的内部上拉最小70kΩ与外部1kΩ下拉形成的开盖电压约VDD/71，低于0.3VDD。
- SN74LVC2G17DCKR：6脚DCK，而不是不存在于本次准确匹配中的DCUR变体。1A=1、GND=2、2A=3、2Y=4、VCC=5、1Y=6。第一路把/RESET的慢上拉边沿整形成锁存器/CLR；第二路整形ARM输入，输入100kΩ下拉，不能悬空。供电3V3_AON。
- SN74LVC1G74DCUR：CLK=1、D=2、/Q=3、GND=4、Q=5、/CLR=6、/PRE=7、VCC=8。D、/PRE固定高；CLK接整形后的ARM；Q控制主供电许可并设100kΩ失电下拉，/Q未用可悬空。禁止把/PRE和/CLR同时拉低。其上电初态不作为安全依据，必须由TPS3808复位清零。
- MCU正常关机完成后通过开漏方式拉低复位总线，或经独立开漏门控清零；不得把推挽输出直接与/RESET相争。ARM原有主电源控制资源可复用，现分配 PB5 RUN_OK 经 SN74LVC1G07 拉低复位总线，PB4 ARM 产生开机沿。
- 只有在盖稳定关闭、电源有效、检测到一次新的电源键动作后，监督器才发ARM上升沿。盖关闭本身不会产生CLK脉冲。启动前ARM拉低，复位释放后满足锁存器恢复时间，保持正常D建立/保持要求。普通机械触点不能直接当CLK。
- 开盖或失电先异步清零，不等Linux响应；正常维护必须先Linux关机。关盖释放复位但Q仍为0；随后主动按键才能重新启动。MCU复位/看门狗和充电器复位的失效状态还须在完整原理图中闭合。

这一方案不承诺单一触点粘连后的功能安全。硬件/机构验收必须包含卡住、断线、触点抖动、上电斜坡及掉电反灌。盖必须从几何上拒绝插头，且从开始释放触点到能插入端口之间留够切断和放电时间；插头在位时不能闭盖允许供电。不能仅用警告标签或松脱防尘塞满足要求。

### 联锁状态表（设计意图）

| AON有效 | 盖闭合 | 新开机请求 | 输出状态 |
|---|---|---|---|
| 否 | 任意 | 任意 | 禁止，电源使能硬下拉 |
| 是 | 否/断线 | 任意 | 异步复位，禁止 |
| 是 | 由开到闭 | 无 | 复位释放后仍禁止，不自动重启 |
| 是 | 稳定闭合 | 有且其余条件有效 | 锁存允许 |
| 是 | 原已开启后开盖 | 任意 | 异步断开；文件系统可能受损 |

## 静态电源预算

- 延续5.1V±2%、Pi支路3A（已含500mA原生USB外设和暂定100mA风扇），LCD/逻辑0.1A及设计余量0.1A，另加入 GPIO 模块 0.1A，当前总设计目标 3.3A。
- 在SYS≥3.5V、效率≥85%、AON≤30mA的前提下，按5.202V输出上限和3.3A计算，电池通路约5.80A，小于6A连续额定，但这不能涵盖短路、启动或低电压。
- TPS259470L数据表p9规定3A时RON最大45mΩ。预留其他整回路（TPS22990、铜、插针和地回流）≤35mΩ，则最低Pi输入计算为5.1×0.98−3×(0.045+0.035)=4.758V。它仅比本设计4.75V静态验收目标高8mV；必须实测/提改善，绝不能将该算式当作动态欠压通过。
- 不能简单把Pi eFuse设到“3A左右”就认为保护了6A BAT通路。按TI p31 RILM=3334/ILIM计算的名义值还须和全温公差、浪涌、电感峰值及上游额定联立；故障限流、ITIMER、升压限流/UVLO与系统响应由原理图阶段计算。没有声明一个尚未成立的满载到低电量工作范围。
- 低电量提前关机、3A供电启动、外部电源切换不重启、USB-C降档和热测试都保留为验收项，不取消用户500mA要求。没有电池型号不阻塞电路设计，但未验证电池不能直接带满载上电。

## LCD过压：有明确静态设定，仍需动态验证

采用TPS259470L独立支路。OVLO上臂34.4kΩ、下臂10kΩ、均0.1%；TI p9阈值1.183–1.223V，漏电±0.1µA。按输入最高触发角落计算：

```text
Vtrip_min = 1.183*(1 + 34400*0.999/(10000*1.001)) - 0.1uA*34400*1.001
Vtrip_max = 1.223*(1 + 34400*1.001/(10000*0.999)) + 0.1uA*34400*1.001
```

最小阈值须高于稳态正常上限5.202V，最大阈值须低于LCD上限5.5V。采用6.65kΩ RILM，数据表给约0.5A名义阈值，非LCD正常耗流。支路损耗和LCD最低4.8V仍须在实际负载检查。

这是过压**断开**，不是理想瞬时钳位。有限响应时间、故障上升速度、输出电容、电源寄生和接线瞬态仍可能造成过冲；在完成动态分析和必要抑制网络前，不能宣布屏幕过压保护测试通过。保留输入至少0.1µF、输出至少1µF有效近端去耦的参考要求，ILM寄生电容小于50pF，精确dV/dt/ITIMER及保护器件由PCB实施选择。没有复制TI p49的双输入并联应用；本设计是两个独立负载分支。

## GPIO插座生产图已落实

Samtec SSQ-120-02-G-D：原厂RevBH系列图p1给壳长20×2.54+0.51=51.31mm、双排宽4.95mm参考、壳高8.51mm参考、-02焊尾4.93mm；0.64mm方尾。原厂RevA推荐PCB孔位p1 Fig1为2×20、2.54mm横纵间距、孔径1.02mm，长向首末孔48.26mm。图纸未给出本项目焊盘铜环或针脚电气编号，不能把孔位图称为完成的PCB封装。

- 电源使用物理2/4，地用全部已分配GND；3.3V不从基板灌入Pi。
- 引脚映射以Pi物理针号及实际插接面核对；底面贴装/翻转时重新验证，不按Samtec通用编号猜Pi奇偶行。
- 插座自身高度不是固定柱高度。CAD阶段按真实Pi排针露出长度、允许插入3.68–6.35mm、板厚和散热器建立公差链，再选择固定柱。不能凭8.51mm直接买8.5mm柱。
- Pi仍需独立机械支撑及防偏排。风扇线束由工厂接到基板专用引出接口，用户不增加焊接或散线跳接；具体线束封装与路径属于布局/装配任务。

## 进入电气实现前已作出的选择

电池责任及电气接口、GPIO插座准确型号和原厂孔位、独立Pi/LCD保护器件、联锁复位/边沿整形/锁存准确型号均已确定。没有等待用户再选一个芯片。

后续必须完成：验证新增电路的实际布线及 DRC；闭合 GPIO 信号保护，选定功率阻容的具体型号并验证补偿/瞬态、容差和热设计，再做制造导出。物理板间堆叠、最终电池尺寸、温升、关机和无重启测试不能以BOM ready代替。
