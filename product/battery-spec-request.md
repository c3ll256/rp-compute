# 3.7 V / 3300 mAh Li-ion 完整保护包资料清单

用户现已决定自备兼容电池。当前接口规范以`battery-interface.md`为准；以下保留为验收资料清单，不再是基板设计前置选型任务，也不是下单文件。

## 已由用户确定
- 标称电压：3.7 V。
- 标称容量：3300 mAh。
- 化学体系：Li-ion。
- 用户自带Raspberry Pi 4 Model B的GPIO基板终端（4GB为参考默认值）；USB-A 500mA，独立电池运行。

## 实際电池到手后核对的资料
1. 工厂完整保护包的准确型号、容量测试条件和最低容量；不得以裸电芯参数替代整包。
2. 整包持续/瞬态放电电流、允许温度、保护动作范围与延时、恢复条件；所需电流按已选Pi4B与电源路径重新预算，不能用 3300mAh 推断。
3. 推荐和最大充电电压/电流及温度范围，供充电器配置和温度监测匹配。
4. 引线线规、长度、连接器型号、极性与应力释放；当前板侧默认XT30U-M，配厂家端接的XT30U-F电池线束；不是要求用户自行焊改电池。
5. 包含保护板、绝缘与突出物的完整尺寸、公差、重量、出线位置；不推定为 18650、21700 或某种软包外形。
6. 放电曲线、内阻及使用寿命条件，用于低电量关机与实际续航评估；不设两小时最低续航门槛。

优先现成的工厂保护包，不直接焊接电芯、改造带电包或旁路保护。旧 6000mAh product 870 不符合此次容量要求，已退出活动 BOM。Pi4B选定后原Zero电源预算仍无效；不得拿旧电池额定值直接套用。价格/库存/交期缺失仅作采购提示。

## 本轮供选型使用的电流条件
预算5.1V±2%、3.2A输出、SYS≥3.5V、效率≥85%、常开30mA，计算电池通路5.6254A。工厂完整保护包暂定采购目标≥8A持续（约2.42C），需PCM与接头同样支持；不是已证实的电池规格。BQ25622仍为6A通路，不能因电池更强而提高。当前可编程目标为480mA／4.2V，须覆盖实际电池允许范围及芯片容差；未知包保持禁充。记录完整最大尺寸、低温/老化曲线、内阻、保护阈值与延时，供提前关机余量评估。
