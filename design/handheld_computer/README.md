## Making and assembly

### 打印

- 默认 PLA、0.2mm 层高，建议 0.4mm 喷嘴。自成形孔先打印校准件试配。
- 上壳顶面朝下平放。前部上沿1.6mm面倒角和下沿浅内收随打印向上逐渐展开；在切片预览中核对45°面边缘。侧孔和接口上沿需在切片预览中复核桥接，不能沿用旧开孔的桥接结论。
- 底盖外底面贴床，0.6mm下沿倒角向上展开，定位边内移0.6mm并让开Pi托架；定位边、纵筋和后接口填块朝上，无主板立柱。底盖与本版上壳按同一外轮廓配套。
- Pi 托架完整平底贴床，三处平耳、四个 Pi 支撑垫和横梁从同一底面长起；沉头孔朝下并沿高度向内收口。当前托架对底盖的最小名义间隙为 0.30mm，须按翘曲和孔补偿试配。该侧长梁已取消，仍以另一侧纵梁和前后横梁支承四个安装孔。
- 拓展盖板用机身同色材料，平整底面朝下，四角沉头孔朝上；R6角、1.0mm上沿倒角，实厚及凸出均1.8mm，无底部定位凸起。
- 屏舱前框将25°屏幕正面旋转至贴平热床，后压框原底面贴床、压边朝上。浅分界线和局部桥接须在切片中复核，不宣称已经实打免支撑。后部抬高后检查内部操作井桥接和支撑；切片时检查前沿首层，不沿用旧件切片。
- 沉头打印补偿保持直径 +0.4mm、深度 +0.2mm。
- 后软垫为裁切件：按新轮廓在前边条左侧切出 5.8×1.6mm 缺口。

- 深色屏圈采用遮蔽喷涂，在装玻璃与泡棉之前完成；保留外圈橙色，遮蔽通光区域、泡棉座和螺孔。先用废料试喷，充分固化后再装屏。screen_face_finish仅为涂层工艺示意，不作为打印零件。

- 侧围板以外侧大平面（带沉头孔开口的一面、世界X38mm面）朝下贴床，背部三个接口凸台朝上；默认PLA、0.4mm喷嘴、0.2mm层高，建议4mm brim。孔内约7.6–11mm短桥接需检查切片预览，不宣称已经实打免支撑。保留原72mm壳体安装座，只重打围板；不要再次打印上壳。
