# 手持终端外壳 — 矩形基板同步版

当前模型绑定矩形 PCB 发布 69ac26497e08aced1b2858ee0777f8e5f23b9fe97a135c3ad144ca151cb584af，STEP SHA256 d5eedbdd2e46ee9693cc34f90c7cba7747c453ec3ba94badc9c13c7c85ab0b27。PCB 位置 (-100,81,21.0)mm，零旋转。机身尺寸保持 76×115mm，13° 屏舱，暖白外壳配橙色屏框。外形简化集中在底板及其配合结构，Pi 和外部接口位置不动。2026-11-07 起屏幕平面整体降低 0.8mm，详见下文“屏幕高度与屏线”。

## 屏幕高度与屏线

主板为配合 8mm Pi 插座下移到板底 Z21.0 之后，屏线从玻璃边到 J_LCD 插口需要下降 4.98mm，在 Sharp 规定的 0.8–6.0mm 折弯区内折不下来。为此把屏幕平面整体降低 0.8mm：

- 屏幕有效区中心 Z 从 35.31 降到 34.51，参数 fascia_screen_center_z 从 8.0109 改为 7.2109；
- 屏舱底座、接缝和 13° 斜面不变，屏舱前沿高出底座 0.575mm（含 0.3mm 分缝，高出平台 0.875mm）；
- 上壳的后压框耳让位井与前框共用同一屏幕基准，前框会校验两者一致。

降低后屏线下降量为 4.08mm。插入深度按规格书剖面取 2.7mm，13.2/13.7/14.2mm 三种屏线的最后一道弯分别在离玻璃边 5.58/5.75/5.91mm 处结束，全部在 6.0mm 以内。屏线带（靠近玻璃一段按 9.5mm 宽计）到前框 0.58mm、玻璃 0.80mm、上壳 ≥2.2mm、前软垫 1.63mm。

如果实际插入只有约 1.9mm，14.2mm 的屏线会超出折弯区。这是样机的第一项检查。

配套改动：
- 屏舱前部两颗固定螺丝从 Y4.2 移到 Y9.2，保证盲孔上方仍有面皮；
- 基板左后导轨收为 7mm 长、Y22–29，后端仍与板后边齐平，让开下降后的后压框 0.39mm；
- 2mm 后软垫前边条在 Pi 排针最前两根尾端上方开 5.8×1.6mm 缺口，间隙 0.67mm，软垫仍为一整块。

Pi 排针尾端到后压框 0.91mm、到上壳 0.585mm，与改动前相同。基板元件到后压框最小 0.56mm，到前框 1.54mm。

J_LCD 信号已核对：屏幕①脚 SCLK 接座焊盘 10（+X），⑩脚 VSSA 接焊盘 1，座端子 = 11 − 屏幕端子。对应 Pi 引脚：GPIO11 接 23 脚，GPIO10 接 19 脚，GPIO8 接 24 脚，GPIO12 接 32 脚，GPIO25 接 22 脚，屏幕电源使能 GPIO24 接 18 脚。信号经 3.3V 缓冲，满足屏幕高电平 ≥2.7V 的要求。

## 矩形板与安装受力

PCB 由 44.5×83.5mm 异形板改为 43.5×68.5mm 完整矩形，面积由 3457.25mm² 降至 2979.75mm²，减少 13.81%。取消了局部缺口、窄颈和后端台阶，保留 0.8mm 四层 FR4。两处 Ø2.2mm 固定孔的世界坐标为 (±16,-32)mm；孔边到左右板边最小 2.9mm，到前板边 6.4mm。

基板仍由两颗 ISO4762 M2×3 直接固定到上壳：6mm 宽横梁与顶板连续，打印接收啮合 2mm。左后导轨长 7mm，支承厚度 1.5mm，侧隙 0.3mm。两处 Ø5mm 承压环按 Ø3.4mm 中心排除区检查，缺失材料均为 0。Pi 使用独立托架固定，模块盖、底盖和 GPIO 焊点都不是唯一支承。

上壳按新发布的 28 个普通器件外形做了避位。普通器件避位上方最薄顶皮 2.055001mm，GPIO 长焊脚凹腔顶皮至少 2mm。最终上壳为一个有效实体。

Pi、散热片和托架沿 -Z 退出 16mm 的路径已检查无首次重叠（变更前结果；本次改动未涉及 Pi 及其托架）。Pi 针脚与示意母座之间 32.850667mm³ 的共享体积仍记为 nominal_contact，只代表未建出的内部插入空间，不认证接触力、寿命或公差。

## 当前装配基准

板底 Z21.0mm，成品板顶 Z21.8mm。8mm GPIO 母座与 5mm 目标通孔模块母座使用发布模型中的名义外形；Pi 与散热片保持前版升高 1.3mm 的姿态。两只母座后焊，断电插拔。GPIO 官方针尖名义插入 3.885mm。模块座到平盖板净空 0.205001mm，不能用盖板螺丝压低母座。

P165-B 保持独立 Pi 托架固定，底盖只负责封闭。机内无风扇，原通风孔作为被动通风保留。屏框为一体前框加 2mm 等厚后压框，配 0.2mm 前软垫和 2mm 后软垫。13.7±0.5mm 原生 FPC 总长是授权估计值；装配时须确认补强端、入槽深度、露铜朝上和受控折弯，不得拉伸排线，玻璃不进入螺丝夹紧叠层。

## Making and assembly

### 打印

- 默认 PLA、0.2mm 层高，建议 0.4mm 喷嘴。自成形孔先打印校准件试配。
- 上壳顶面朝下平放。侧孔和接口上沿需在切片预览中复核桥接，不能沿用旧开孔的桥接结论。
- 底盖外底面贴床，定位边、纵筋和后接口填块朝上，无主板立柱。
- Pi 托架完整平底贴床，三处平耳、四个 Pi 支撑垫和横梁从同一底面长起；沉头孔朝下并沿高度向内收口。底盖平面间隙 0.6mm，计入沉头螺丝后最小名义间隙 0.4mm，须按翘曲和孔补偿试配。
- 拓展盖板平整底面朝下，四角沉头孔朝上；无底部定位凸起，盖板凸出 2.4mm。
- 屏舱前框以 13° 屏幕正面贴平热床，后压框大平面贴床。浅分界线和局部桥接须在切片中复核，不宣称已经实打免支撑。屏舱比上一版矮 0.8mm，前沿更薄，切片时检查前沿首层。
- 沉头打印补偿保持直径 +0.4mm、深度 +0.2mm。
- 后软垫为裁切件：按新轮廓在前边条左侧切出 5.8×1.6mm 缺口。

### 紧固件

沿用现有螺丝：M3×6 模块盖/底盖螺丝、M2×3 基板螺丝、M2×6 托架螺丝、M2.5×6 金属散热片螺丝，以及屏舱既定的 M2×4/M3×6 螺丝。不新增采购件。基板不加垫片，也不换长螺丝。

### 装配顺序

1. 将带导热垫的 P165-B 对准 Pi，放到独立托架的四个支撑垫上，从托架下方用四枚 M2.5×6 沉头螺丝拧入金属散热片，交替轻紧。先核对实物螺纹深度和垫片接触，不要靠螺丝力强压芯片。
2. 屏舱前面朝下，依次装 0.2mm 无胶前垫、玻璃和 2mm 无胶后垫（缺口朝 Pi 排针一侧）。后压框四耳落到硬止口，用四枚 M2×4 沉头交替轻紧，禁止靠拧紧强压玻璃。原生排线向背面折一次：均匀拉开 J_LCD 抽屉两端，补强端露铜朝上插到底，再推回抽屉。将前框四脚落到上壳承力舌，从上壳内侧拧入屏舱螺丝。此时不要装 Pi 托架。
3. 完成 SMT 和两只通孔母座后焊。将矩形基板沿左后导轨就位，让它自然坐到横梁和导轨上，再用两枚 M2×3 轻紧。插拔时支撑连接器附近，不要用螺丝把偏斜的插针拉入。
4. 保持上壳倒置，将 Pi/散热片/托架组件从底部沿槽口竖直装入。观察 GPIO 对位，最后约 5mm 手工插入母座，不能用托架螺丝拉紧 GPIO。三处托架耳坐实后，从底部拧入三枚 M2×6，交替轻紧。
5. 核对 microSD 和所有接口后装底盖，四枚 M3×6 沉头从下方对角交替轻紧。拓展盖板自然贴合平台后用四枚 M3×6 固定，不要用螺丝强拉翘曲的盖板。

拆机前先软件关机并断电。卸下底盖后，Pi、散热片、基板和 GPIO 连接都留在上壳上；拆 Pi 时卸下三枚托架螺丝，沿 -Z 竖直拔出。拆屏舱前必须先移出 Pi 托架，再拉开 J_LCD 抽屉、脱开排线，然后从内侧卸屏舱固定螺丝。不要误卸压玻璃的后压框螺丝。

## 验证边界

- 模块盖净空 0.205mm 很紧，须核对实物母座高度和打印平面度。
- 几何支承检查不能替代 FR4 挠曲、载荷、扭矩、跌落、插拔循环或温升测试。
- 尚未做过实物打印、完整排线接插、反复拆装或热测试。屏线实际长度和 J_LCD 实际插入深度决定折弯是否留在 6mm 内，须在样机上确认。
- 侧孔须用实际的 USB-C、micro-HDMI 和音频线确认插入、拔出及胶壳间隙。
- P165-B 局部外形为参照模型，不是供应商认证几何。
