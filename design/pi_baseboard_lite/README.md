# 76mm窄边机身基板

用户接受为收窄fascia和机身而改板。本板保留现有电气拓扑、器件型号、物理针序、正面SMT/背面GPIO母座、四层内外1oz与0.8mm成品厚度。

Pi与散热片整体向左移动5mm；J_PI从板坐标(-13.5,21)移至(-18.5,21)。屏幕FPC座J_LCD仍为(0,24.65)，上接触、朝-Y，原生排线无需因Pi移动而产生额外横向位移。模块座和J_FAN插座保留原坐标；当前整机取消风扇及线束，已有J_FAN保持装配但不使用。

板框外包络44.5×83.5mm，左边界扩到X-24.5mm，为移动后的GPIO座留出板边空间；左前屏幕压框螺丝位移到X-27，板边局部收至-23.5避开其耳部。右前螺丝移至+27，原右侧屏幕螺丝避让凹口取消。PCB两枚2.2mm安装孔仍为(-16,-13)、(16,-13)，板底装配高度21.8mm。

物料记录已按当前外壳/紧固件方案修正15项派生描述及身份；六颗IC和接口均显式声明供电、接地、输入输出、开漏FAULT及24个有意悬空端子。Pi的5V、3.3V和GND各用一个端子代表同一外部来源，其余同轨触点按被动连接处理，避免把冗余触点误认为独立电源。缓冲器采用输入左、输出右、电源上、接地下的功能符号。实际器件、焊盘和网络未改变。

## Making and assembly

先一次贴装正面SMT器件并回流，再装Pi背面通孔母座及需要单独焊接的连接器。全板按用户自行买料焊接准备，正面SMT优先使用可控回流或热台，背面Pi母座后焊。0.5mm FPC座和0.65mm TSSOP需放大检查连锡；必须使用与当前板匹配的位号装配图。自动贴片订单审核不属于本次自焊交付。

先不装屏幕和模块，检查无短路，由Pi USB-C供电，测试受控显示电源、两路限流及FAULT。COM波形及关机时序验证后再装屏。模块仅断电更换，3.3V逻辑、默认100mA预算。

装屏时先打开屏舱取得滑盖操作空间，露铜向上插入并关闭锁扣，再固定屏舱。屏幕补强端4mm恰好达到新座推荐下限，需样板核对夹持和止挡。13.7±0.5mm原生排线总长仍是已授权估计；不得拉伸排线或放宽折弯半径。Pi堆叠公差、M2固定、实际贴装流程及热性能仍须试装。
