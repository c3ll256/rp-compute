# 76mm窄边机身基板

用户接受为收窄fascia和机身而改板。本板保留现有电气拓扑、器件型号、物理针序、正面SMT/背面GPIO母座、四层内外1oz与0.8mm成品厚度。

Pi与散热片整体向左移动5mm；J_PI从板坐标(-13.5,21)移至(-18.5,21)。屏幕FPC座J_LCD仍为(0,24.65)，上接触、朝-Y，原生排线无需因Pi移动而产生额外横向位移。模块座和风扇插座维持原坐标，风扇本体在外壳内向右移动3mm并向前移动3mm。

板框外包络44.5×83.5mm，左边界扩到X-24.5mm，为移动后的GPIO座留出板边空间；左前屏幕压框螺丝位移到X-27，板边局部收至-23.5避开其耳部。右前螺丝移至+27，原右侧屏幕螺丝避让凹口取消。PCB两枚2.2mm安装孔仍为(-16,-13)、(16,-13)，板底装配高度21.8mm。

本版布线完成，KiCad DRC为零错误、零警告、无未连接项；39个走线过孔均为0.6/0.3mm。裸板制造与机械集成部分已发布；BOM装配策略仍是手工样板/正面回流，不宣称嘉立创自动贴片订单已确认。工具的部分SVG转PNG和Gerber外观预览生成存在环境故障；已直接转换并查看当前SVG布局及查看布线和3D装配图，不把外观渲染故障当作电路或制造检查通过的替代证据。

## Making and assembly

先一次贴装正面SMT器件并回流，再装Pi背面通孔母座及需要单独焊接的连接器。全板默认手工样板/正面回流装配；嘉立创自动贴片订单的料号、机器旋转及在线放置预览没有完成审核，不宣称可直接付款。

先不装屏幕和模块，检查无短路，由Pi USB-C供电，测试受控显示电源、两路限流及FAULT。COM波形及关机时序验证后再装屏。模块仅断电更换，3.3V逻辑、默认100mA预算。

装屏时先打开屏舱取得滑盖操作空间，露铜向上插入并关闭锁扣，再固定屏舱。屏幕补强端4mm恰好达到新座推荐下限，需样板核对夹持和止挡。13.7±0.5mm原生排线总长仍是已授权估计；不得拉伸排线或放宽折弯半径。Pi堆叠公差、M2固定、实际贴装流程及热性能仍须试装。
