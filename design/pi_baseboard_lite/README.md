# 屏幕与8针GPIO精简基板

用户确认2.54mm、2×4直立母座，由Pi 4B原生USB-C供电。本版提供Sharp LS027B7DH01的10芯0.5mm FPC接口和可换模块接口，没有电池、充电、升压、MCU或音频。原电源完整版保存在pi_baseboard。

## 已实现电路

两个TPS2553独立限制显示和模块支路电流，两个TLV75533分别提供缓冲器和模块3.3V。显示五个信号经SN74AHC125缓冲。GPIO24控制显示电源，GPIO12产生外部COM，GPIO25控制DISP，GPIO16读取合并故障信号。

| J_MOD针号 | 信号 | Pi物理针 |
|---|---|---|
| 1 | AUX_3V3，100mA模块预算 | 本板独立稳压 |
| 2 | GND | 公共地 |
| 3 | GPIO2 / SDA | 3 |
| 4 | GPIO3 / SCL | 5 |
| 5 | GPIO10 / MOSI | 19 |
| 6 | GPIO9 / MISO | 21 |
| 7 | GPIO11 / SCLK | 23 |
| 8 | GPIO7 / CE1 | 26 |

这不是Pi前8针的同序接口。软件可将总线针复用为GPIO；屏幕工作时必须保留共享SPI时钟和MOSI。屏幕使用独立、高有效CE0；扩展模块使用CE1，只允许本板供电的3.3V逻辑，断电插拔，无热插拔和外部模块电源支持。

母座为Samtec SSQ-104-02-G-D，标准KiCad 2×4母座封装、1.0mm钻孔，壳高8.51mm、焊尾4.93mm。按母座原生针号保留上表功能，不能直接沿用旧公针的物理行顺序。

## 紧凑版布局

按用户反馈缩小FPC与扩展板。当前采用单片L形板：外包络40×83.5mm，Pi接口窄条宽15mm，下端电路区域40×25.5mm，内角3mm斜切。以上尺寸是本轮布局默认值（source=default），不是用户指定尺寸。板材净面积1894.5mm²，相比进入本轮时的70×89mm矩形减少69.6%，相比旧发布70×104mm减少74.0%。长边仍由40针Pi直插母座及前方模块接口的间距决定。

保留31个实装元件、全部型号和电气连接。缓冲器移至FPC附近正面，显示和模块的限流/LDO支路集中在背面。两枚2.2mm工装孔位于(-16,-13)/(16,-13)mm，配2.5mm半径禁布区；仅为样板固定点，外壳尚无对应支柱。双层1oz、1.6mm板厚，原线宽、电流预算和间距规则保持。

## 接口坐标与机械影响

板坐标与本次进入前一致（+Y向Pi后端），L形外轮廓X=-20..20、Y=-35.5..48mm。Pi母座背面中心(-13.5,21)mm：已让实际器件引用原布局中声明的21mm基准，消除旧主源码仍写15.2mm的矛盾。FPC正面原点(0,-17.7)mm、旋转180°、开口朝+Y；扩展母座正面针阵列中心(0,-31.97)mm、沿+Z插接。FPC/扩展口沿用进入本轮时的源码位置。

旧CAD仍装载70×104mm发布板，不能用来查看本轮L形板。若将Pi母座对准已记录的世界坐标Y=2mm，新的板前缘为Y=-54.5mm，相对壳内前边Y=-55.1mm仅有0.6mm名义余量；这只是平面核对，没有验证Z向装配、公差或连接器实体。扩展针阵列中心成为世界Y=-50.97mm，仍不在现有前面板开孔Y=-47..-21mm范围内。FPC原点成为世界Y=-36.7mm，与倾斜屏舱内原目标Y=6.76285mm及其姿态不一致。后续装壳必须修正接口布局/连接方式，不能宣称原生短排线已经接通，也不能直接扩大壳体掩盖此问题。

两工装孔、板轮廓、Pi插座中心及缓冲器位置相对旧发布均已变化，需要重新适配固定与排线。保留定位槽、1mm屏舱前沿和用户设置的电源帽；本轮没有修改CAD。

## 当前外壳接口核对

本次请求保留紧凑板并按外壳和排线重排。已按当前外壳核对：扩展针阵列需由世界Y=-50.97mm移至开孔中央Y=-34mm（板坐标中心Y=-15mm），偏移16.97mm。原排线目标在世界Z=27.2545mm且随屏幕倾斜倒置，现有水平主板上的侧插FPC座仅改XY不能接合。

具体候选为竖插FH12-10S-0.5SV(55)、低矮Pi母座SLW-120-01-G-D和扩展母座SLW-104-01-G-D；不是已选替代料。Samtec图纸给出壳高4.57mm、允许插入2.16–2.92mm，Hirose图纸给出竖插座闭合高3.6mm、开锁高5.5mm。低壳高并不意味着可等量降低主板：仍须验证Pi针长与插入范围。原生排线自由长13.7mm只是旧版估计，不能当成厂商公差尺寸证明可装配。核对和候选记录见enclosure-interface-review.json。

已询问是否允许替换这三个既定型号；选择到达前不改选定BOM或制作依赖该替换的布线。若保留现有连接器，必须另行重做屏幕安装与排线折弯。现有连接器的当前布置不能同时满足已记录的排线终点姿态和水平单板直插，故本轮没有宣称重排或布线验证完成。

## 验证状态

本轮布局编译和元件/板边检查已通过，已检查正反面预览。信号网络已布通；最终check仍被GND连通性阻止：8条原始未连接报告，归并为5项阻塞（4项未连接及1项铜皮分裂）。局部接地过孔修复减少了问题，但Pi母座与显示限流附近仍有接地断开，因此没有发布新版Gerber、STEP或制造包。下一步应重做这些位置的接地回路，不能沿用旧版生产文件。旧版的零DRC错误记录只适用于旧发布，不能转用于本版。未上电实测或编写驱动，显示波形、负载温升、压降、故障响应、短FPC长度与插接方向仍待样板验证。

## Making and assembly

全板按手工样板装配，不声明JLC自动贴片套餐可直接下单。先焊背面小件，再焊正面FPC座、缓冲器及电源支路，最后焊40针母座及8针母座；核对1脚后再装Pi。实际装配顺序仍需样板验证。

首次不装屏幕和模块，检查无短路，再由Pi USB-C供电，测试3.3V模块支路、GPIO24控制的显示5V及两路限流/FAULT。屏幕端实测须保持4.8–5.5V；驱动准备好且COM波形验证后才接屏。工装孔不替代Pi的独立固定。
