# 屏幕与8针GPIO基板

采用首韩0.5-10P CTSJ-H2.0 119 / C5373447：10针、0.5mm间距、上接触、0.3mm排线、抽屉锁扣。正面入口朝-Y，座端子=11−屏幕端子。使用精确供应商封装及下载的详细库STEP，保留屏幕信号和供电拓扑。模型来源：嘉立创EDA/EasyEDA官方库，https://lceda.cn/，https://easyeda.com/。

用户允许扩大板面以避免拥挤。默认外包络保留40×83.5mm，填补原中央/显示区内凹空间；保留Pi母座、模块口、安装孔和屏幕螺钉避让口的机械基准。四层、内外1oz、0.8mm厚。

所有实装器件都在正面，背面只保留Pi的40针ESQ-120-12-G-D母座。两颗TSSOP14均放在正面并分开；旁路电容跟随各自VCC端。J_FAN改到正面后部向-Y开口，避免把高连接器挤在前模块盖下。8针HLE-104-02-G-DV的位置及Pi的40个物理针序保持原设计。

本版编译、全连接、DRC和DFM已通过。面积3025.83mm²，比原版增加32.448%；普通元件焊盘包络距板边至少2.067997mm。两颗TSSOP14到FPC焊盘包络的间距约9.40mm/4.38mm，各自100nF电容到VCC焊盘中心约2.7mm。板边右侧局部避让现有屏幕支架及螺钉；风扇接口已移至正面后部(0,34)。现有外壳仍绑定旧PCB；正面限流芯片到原壳内顶面约0.455mm，未达到保留的1.5mm默认目标，需在后续CAD阶段处理。结果以最终发布和核对记录为准。尚未测试上电波形、COM持续性、native-tail夹持和温升。

## Making and assembly

先一次贴装正面SMT器件并回流，再装Pi背面通孔母座及需要单独焊接的连接器。全板默认手工样板/正面回流装配；嘉立创自动贴片订单的料号、机器旋转及在线放置预览没有完成审核，不宣称可直接付款。

先不装屏幕和模块，检查无短路，由Pi USB-C供电，测试受控显示电源、两路限流及FAULT。COM波形及关机时序验证后再装屏。模块仅断电更换，3.3V逻辑、默认100mA预算。

装屏时先打开屏舱取得滑盖操作空间，露铜向上插入并关闭锁扣，再固定屏舱。屏幕补强端4mm恰好达到新座推荐下限，需样板核对夹持和止挡。13.7±0.5mm原生排线总长仍是已授权估计；不得拉伸排线或放宽折弯半径。Pi堆叠公差、M2固定、实际贴装流程及热性能仍须试装。
