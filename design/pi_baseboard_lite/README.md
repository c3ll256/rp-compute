## Making and assembly

嘉立创仅代贴正面29个器件。J_PI背面2×20、8mm塑高、3.5mm焊脚通孔母座，J_MOD正面2×4、2.54mm通孔母座从JLC清单排除，按BOM规格另购并后焊；屏幕玻璃不进SMT。厂商回流后再安装这些连接器，检查0.5mm FPC座和0.65mm TSSOP连锡。必须使用同一最新发布的Gerber、JLC BOM和JLC CPL。上传嘉立创后先核对器件居中、6颗IC一脚和J_LCD朝向/接触面，返回贴装预览供检查，再付款；本地审查不代表已审核嘉立创订单。

先不装屏幕和模块，检查无短路，由Pi USB-C供电，测试受控显示电源、两路限流及FAULT。COM波形及关机时序验证后再装屏。模块仅断电更换，3.3V逻辑、默认100mA预算。

装屏时先打开屏舱取得滑盖操作空间，露铜向上插入并关闭锁扣，再固定屏舱。屏幕补强端4mm恰好达到新座推荐下限，需样板核对夹持和止挡。13.7±0.5mm原生排线总长仍是已授权估计；不得拉伸排线或放宽折弯半径。Pi堆叠公差、M2固定、实际贴装流程及热性能仍须试装。

两只母座均为通用规格件，不继承旧Samtec最小插入量。40Pin针位保持原位置，物理Pn现在直接对应焊盘n。8Pin一脚为AUX_3V3、二脚GND，随后为GPIO2/3/10/9/11/7；方焊盘标记一脚。模块固定螺丝独立承担载荷，拔插时支撑PCB。8Pin塑高5mm、焊脚3mm、塑壳10.16×5.08mm与0.64mm方针为默认，实物须匹配。
