# 屏幕与8针GPIO精简基板

用户确认2.54mm、2×4直立公排针，由Pi 4B原生USB-C供电。本版提供Sharp LS027B7DH01的10芯0.5mm FPC接口和可换模块接口，没有电池、充电、升压、MCU或音频。原电源完整版保存在pi_baseboard。

## 已实现电路

两个TPS2553独立限制显示和模块支路电流，两个TLV75533分别提供缓冲器和模块3.3V。显示五个信号经SN74AHC125缓冲。GPIO24控制显示电源，GPIO12产生外部COM，GPIO25控制DISP，GPIO16读取合并故障信号。

| J_MOD针号 | 信号 | Pi物理针 |
|---|---|---|
| 1 | AUX_3V3，100mA模块预算 | 本板独立稳压 |
| 2 | GND | 公共地 |
| 3 | GPIO2 / SDA | 3 |
| 4 | GPIO3 / SCL | 5 |
| 5 | GPIO10 / MOSI | 19 |
| 6 | GPIO9 / MISO | 21 |
| 7 | GPIO11 / SCLK | 23 |
| 8 | GPIO7 / CE1 | 26 |

这不是Pi前8针的同序接口。软件可将总线针复用为GPIO；屏幕工作时必须保留共享SPI时钟和MOSI。屏幕使用独立、高有效CE0；扩展模块使用CE1，只允许本板供电的3.3V逻辑，断电插拔，无热插拔和外部模块电源支持。

排针为Samtec TSW-104-07-G-D，标准KiCad 2×4封装、1.0mm钻孔。此前XFCN/CJT候选的供应商封装孔径分别为1.1/1.2mm，超出其推荐孔公差，未进入最终设计。

## 电气样板验证

31个实装元件、4个工装孔。板框70×104mm、双层1oz、1.6mm板厚；输入及模块供电0.5mm、显示5V 0.25mm、缓冲电源0.30mm、GPIO 0.25mm。Pi整机电流不经过本板；输入按0.5A、两支路各0.2A校核，正常模块预算100mA。

布线检查fe523774-4d0a-4d90-a9aa-56d84e57d70f通过：KiCad零错误、零未连通，35条库封装元数据警告。原理图仍有未用Pi针、芯片电气类型元数据和内部连接器方向推断警告，不能视为电路仿真或满覆盖ERC。钻孔实测48个1.0mm镀铜孔、30个0.3mm过孔、4个2.2mm非金属化孔。Gerber、钻孔和板模型已发布；本次运行未返回独立审阅结论。全板手工装配，因此JLC自动贴片BOM/CPL只有表头，不是可下单的贴片清单。

尚未上电实测或编写驱动，显示波形、负载温升、压降和故障响应待样板验证。软件接口及证据见implementation.md。

## 机械边界

本次不改外壳，保留定位槽、1mm前沿和用户设置的12mm电源帽。板框及四角工装孔不是现有外壳支柱的已验证安装尺寸。J_PI背面中心(-13.5,15.2)mm；J_LCD背面中心(0,6.7)mm，排线向板坐标-Y伸出、触点朝PCB；J_MOD正面针阵列中心(0,-34)mm，向+Z插接。标准库排针原点为1脚，源码坐标(-3.81,-35.27)mm对应上述中心。

完整FPC弯折、锁扣操作、Pi/GPIO堆叠及USB-C开口仍需CAD适配。排针标准3D模型是近似外形，当前预览相对焊盘还存在原点偏移，不得用它决定模块定位。短FPC是否无需延长线尚未验证。

## Making and assembly

全板按手工样板装配，不声明JLC自动贴片套餐可直接下单。先焊背面小件和FPC座，再焊正面电源支路，最后焊40针母座及8针排针；核对1脚后再装Pi。实际装配顺序仍需样板验证。

首次不装屏幕和模块，检查无短路，再由Pi USB-C供电，测试3.3V模块支路、GPIO24控制的显示5V及两路限流/FAULT。屏幕端实测须保持4.8–5.5V；驱动准备好且COM波形验证后才接屏。工装孔不替代Pi的独立固定。
