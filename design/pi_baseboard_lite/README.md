# 屏幕与8针GPIO紧凑基板

保留单块紧凑板、水平侧插FPC和原生排线轻弯。31个实装元件及电气拓扑保留；Pi原生USB-C供电，无电池、充电、升压、MCU或音频。

## 当前接口

背面J_PI改为Samtec ESQ-120-12-G-D：40针、2.54mm双排、壳高11.05mm、焊尾2.29mm，允许插入3.68–6.35mm。40个GPIO物理位置和信号已核对；供应商封装相邻排针号相反，源代码已逐对交换逻辑标签以保持Pi实际对应关系。

正面J_MOD改为Samtec HLE-104-02-G-DV：8针、2.54mm双排、SMT、壳高3.66mm。采用保存于项目的官方KiCad焊盘封装，外部采购并手工装配。针号1=AUX_3V3，2=GND，3=GPIO2/SDA，4=GPIO3/SCL，5=GPIO10/MOSI，6=GPIO9/MISO，7=GPIO11/SCLK，8=GPIO7/CE1；不是Pi前8针同序。模块预算100mA、3.3V逻辑，断电插拔，不支持外部模块电源或热插拔。

正面J_LCD仍为Hirose FH12-10S-0.5SH(55) / C506791：10芯、0.5mm、0.30mm排线、底接触。水平入口已旋转到板-Y方向，即装配视图的向下/前方。该底接触选择暂时保留；Sharp厂家推荐将原排线向屏幕后方折回后，露铜面朝上，与当前底接触座存在冲突。建议改用同系列水平上接触FH12A-10S-0.5SH(55)，等待用户选择后才能更改这一既有要求。当前不声明屏幕排线装配通过。

两个TPS2553分别限制显示与模块电流，两个TLV75533分别提供缓冲器和模块3.3V；两个SN74AHC125缓冲显示五个信号。GPIO24控制显示电源，GPIO12产生COM，GPIO25控制DISP，GPIO16读合并FAULT。

## 布局、制造与布线验证

外包络40×83.5mm，净面积2284.54mm²；GPIO窄条局部17mm、尾部15mm、下端电路岛40×25.5mm。板厚0.8mm，四层FR4、内外1oz；GND在top/inner1/bottom铺铜，inner2参与走线。保持0.15mm最低铜间距、1mm铜到板边、0.6/0.3mm通孔过孔，无焊盘内过孔例外。500mA输入采用0.50mm实际走线；按1oz内层IPC-2221、10°C升温计算最低0.31mm，200mA支路最低0.20mm。四层是为回流和拥堵采用的默认实现。

最新检查：DRC零错误、零警告、零未连通，全部信号、电源与GND连通，43枚过孔均为0.6/0.3mm。已查看最新正反面布线，内层铜图也已核对。原始屏幕螺钉位置保持，板边缺口精确间隙1.292813mm，高于默认0.5mm。

## 上壳固定和装配尺寸

板坐标X=-20..20、Y=-35.5..48mm，板到世界XY平移(0,-19)mm；CAD STEP额外含KiCad(+100,-100)原点，导入平移为(-100,81,21.8)mm，零旋转。板底21.8mm是默认尺寸，相对之前17.5mm抬高4.3mm，较22.5mm试配降低0.7mm以保留上方间隙。

J_PI世界针阵列中心(-13.5,2)，J_MOD中心(0,-34)，J_LCD正面原点(0,9.8)，入口朝-Y。两枚2.2mm非金属化孔在源坐标(-16,-13)/(16,-13)，对应世界(-16,-32)/(16,-32)。两枚M2×4螺钉从板底紧固至上壳侧壁引出的支承梁，后部导向台承托板边；固定独立于下盖和可拆前模块面板。螺钉接合采用printed-screw-joint-v1标准组件，标称接合1mm；孔周2.5mm半径保持铜禁布区。

精确逐实体复核：新版PCB基材与元件对上壳、底盖、屏幕框、压框、面板、缓冲垫、指定螺钉及Pi的体积交叠均为零；Pi与新增上壳结构也为零。普通正面元件距结构件最小1.555001mm；8针座顶低于前面板0.745001mm。支承梁距模块面板0.5mm，避让槽上方余壁1.9mm。上述间隙不是温升或气流实测。

ESQ与HLE采用厂家尺寸图建立的明确参考模型，未获得准确内部触点STEP。Pi官方针尖位置给出约4.75mm插入；第三方Pi模型含底面偏移给出6.335mm，距6.35mm上限仅0.015mm，不能据此认定实物公差合格。样板需验证插入深度、接触保持和装壳顺序。

排线长度暂取13.7±0.5mm、非接触间隙每侧0.5mm；这是用户授权的估计，不是实测。抬高板后，旧高度不足已解除，但完整折弯路径、接触面、针1、插入止挡和锁扣操作仍待验证。现有电源按钮与壳体的小交叠保持原状，本次没有修复；不能声明整机无任何碰撞。

## Making and assembly

全板按手工样板装配，不声明JLC自动贴片套餐可直接下单。先焊背面小件，再焊正面FPC座、缓冲器及电源支路，最后焊40针母座及8针母座；核对1脚后再装Pi。实际装配顺序仍需样板验证。

首次不装屏幕和模块，检查无短路，再由Pi USB-C供电，测试3.3V模块支路、GPIO24控制的显示5V及两路限流/FAULT。屏幕端实测须保持4.8–5.5V；驱动准备好且COM波形验证后才接屏。工装孔不替代Pi的独立固定。

当前40针座、8针座和上壳固定取代此前较矮SLW接口与未装壳工装孔状态。先完成FPC接触面选择和排线接插复核，再打印上壳试装；安装两枚PCB紧固螺钉并确认后导向台承托，之后安装可拆模块面板与下盖。板上固定不能替代Pi的独立固定。实际接插公差、PLA螺纹强度、上电显示波形和温升仍需样板实测。
